HTML code blocks

Switch this file to Preview. Each <pre> becomes a code block.

Language on <code> (highlight.js / Prism style): Run + Copy

echo "OK html bash"

Language on <pre>: Run + Copy

echo "OK html zsh"

lang- prefix: Run + Copy

echo "OK html lang-sh"

Transcript: only $ lines run

$ echo "OK html console"
OK html console

Whitespace is kept

for i in 1 2 3; do
    echo "indent kept $i"
done

Escaped markup stays text

echo "<b>not bold</b> &amp;"

SQL: Copy only

SELECT id, name FROM users WHERE active ORDER BY name;

Plain <pre> with no language: Copy only

plain preformatted text
   with    spacing kept

Inline code has no buttons

Run echo inline yourself.
