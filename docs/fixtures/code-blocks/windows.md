# Windows shells

On **Windows** these show **▶ Run + Copy** (the terminal there is PowerShell).
On **macOS/Linux** they show **Copy only**, because zsh/bash can't run them.

```powershell
Write-Output "OK powershell"
Get-Location
```

```pwsh
Write-Output "OK pwsh"
```

```ps1
Write-Output "OK ps1"
```

```cmd
echo OK cmd
```

```bat
echo OK bat
```

```batch
echo OK batch
```
