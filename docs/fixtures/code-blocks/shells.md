# Every shell language

Each block should show **▶ Run** and **Copy**. The commands run in your own
shell (zsh/bash), whatever the fence says, so they stick to plain POSIX `echo`.

```bash
echo "OK bash"
```

```sh
echo "OK sh"
```

```shh
echo "OK shh"
```

```shell
echo "OK shell"
```

```zsh
echo "OK zsh"
```

```csh
echo "OK csh"
```

```dash
echo "OK dash"
```

```ksh
echo "OK ksh"
```

```tcsh
echo "OK tcsh"
```

```fish
echo "OK fish"
```

```console
$ echo "OK console"
OK console
```

```shell-session
$ echo "OK shell-session"
OK shell-session
```

```shellsession
$ echo "OK shellsession"
OK shellsession
```
